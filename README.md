# QuoteGen

QuoteGen is a lightweight Python application for browsing and generating random quotes from a local collection.

## Features

- Random quote
- Categories
- Favorite quotes
- Search
- Export
- Statistics

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python src/main.py
```

Example

```
1. Random quote
2. Search
3. Favorites
4. Export
5. Exit
```
